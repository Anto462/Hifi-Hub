¿Por qué no hay ASIO? Se analizó y se descartó con motivo. Para reproducción, WASAPI exclusivo ya entrega el stream intacto con el reloj del DAC: ASIO no añade fidelidad audible ahí — su ventaja real es la baja latencia al monitorizar mientras grabas, que no es nuestro caso. Además, el motor de audio que usa HiFi Hub (libmpv) no incluye salida ASIO, y el SDK de Steinberg no se puede redistribuir, así que habría que mantener un segundo motor entero —perdiendo el gapless, el ReplayGain y toda la cadena DSP—. Y ASIO4ALL o FlexASIO, por debajo, acaban usando WASAPI igualmente. Preferimos una opción menos que una opción vacía.
Las tareas pesadas (análisis, espectros, lotes, importaciones) siguen avanzando, pero ceden el turno al reproductor. Solo se nota bajo carga: en reposo el motor ya consume prácticamente nada.
